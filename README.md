# KAOK

Organiza tus gastos, ingresos y metas de ahorro desde tu teléfono Android.

**[Descargar la última versión](https://github.com/Rubb9/kaok/releases/latest)**

## Qué puedes hacer

- Registrar gastos e ingresos, como sueldo, trabajos independientes y otras entradas de dinero.
- Fotografiar facturas, revisar los datos reconocidos y guardar una representación digital junto a la foto.
- Consultar estadísticas y el archivo mensual de compras, ingresos y metas.
- Crear metas de ahorro y registrar aportes.
- Usar los temas claro y oscuro.

## Instalación

1. Abre la sección [Releases](https://github.com/Rubb9/kaok/releases).
2. Descarga el archivo terminado en **.apk** de la versión que quieras instalar.
3. Abre el archivo en tu teléfono. Si Android lo solicita, permite instalar aplicaciones desde el navegador o gestor de archivos que estés usando.
4. Completa la instalación y abre **KAOK**.

Requiere **Android 7.0 o posterior**. Los archivos «Source code» que GitHub muestra automáticamente contienen los documentos de este repositorio; no sirven para instalar la app.

## Actualizaciones

Instala el APK nuevo sobre la versión anterior de KAOK, **sin desinstalarla**, para conservar tus registros. Las versiones publicadas aquí usan la misma firma de la app. Las versiones futuras estarán disponibles en Releases.

## Lectura de facturas

La lectura se realiza en el dispositivo. Toma la foto con buena iluminación, con toda la factura visible y el texto enfocado. Revisa los productos, las cantidades, los precios y el total antes de guardar: la lectura automática puede omitir o interpretar mal información.

La factura virtual es una representación para organizar tus registros personales; conserva también el comprobante original.

## Sobre este repositorio

Este espacio distribuye los APK y la documentación de KAOK. El código fuente de la aplicación no se publica aquí.

## Informar un problema

Puedes describir un fallo en [Issues](https://github.com/Rubb9/kaok/issues), indicando la versión de KAOK, la versión de Android y los pasos para reproducirlo. Evita publicar facturas o capturas con nombres, cédulas, direcciones u otros datos personales.
